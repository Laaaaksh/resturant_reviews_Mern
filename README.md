# resturant_reviews_Mern

Planning notes for a MERN-stack restaurant reviews app that was never built. Two commits, July 2021.

## What it is

The repo contains a single `info.txt` with rough notes: MongoDB Atlas for the database, Node/Express for a backend, Node/React for the frontend, and a note that the backend could be made serverless instead. There's a short MongoDB terminology cheat-sheet (collection/document/index/`$lookup` mapped to SQL terms). No application code — no `package.json`, no source files — was ever committed.

## Stack

Planned only: MongoDB Atlas, Node.js/Express, React. None of it was implemented in this repo.

## Running it

Nothing to run — there is no code.

## Status

An early planning stub from July 2021 that the project never progressed past. Not maintained.
